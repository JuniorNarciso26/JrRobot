## Current reference

The current source version on `main` is **`JrBot_V1.8.3S`**. V1.8S integrated JrSkill Network; V1.8.1S added Wi-Fi setup and mDNS recovery; V1.8.2S added **Mesa Mix · Live** for audio tuning; and V1.8.3S introduces the **Wi-Fi dashboard** for checking RSSI/IP/channel, scanning nearby networks, and saving, selecting or deleting stored profiles with a confirmed restart to switch networks. Audio testing reported good headphone communication, but delayed self-voice return remains known. See [Project Status](PROJECT_STATUS.md) and [Wi-Fi dashboard guide](../04-firmware-development/WIFI_DASHBOARD.md) for evidence and limits.

The JrSkill creation, publication, license purchase, and physical execution flow has been demonstrated on **Solana Devnet**. This does **not** imply a live Mainnet marketplace.
